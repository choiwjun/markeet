## 1. Executive Summary

### 제품 개요
**마케트(Markeet)**는 이커머스 셀러를 위한 AI 기반 마케팅 데이터 통합 플랫폼입니다. "데이터를 보여주는 대시보드를 넘어, 다음 행동까지 알려주는 AI 마케팅 파트너"를 지향합니다.

### 핵심 가치 제안
- **시간 절약**: 매일 5.5시간 → 30분 (90% 절감)
- **진입장벽 제거**: 전문 지식 없이도 전문가 수준의 데이터 분석
- **한국 특화**: 네이버/쿠팡 등 국내 플랫폼 완벽 지원

### 비즈니스 목표
- Year 1: 1,000명 고객, 무료→유료 전환율 20% 달성
- 구독 수익: $99~$2,999/월 4단계 플랜

---

## 2. 문제 정의 (Problem Statement)

### 현재 상황
이커머스 셀러들은 네이버 스마트스토어, 쿠팡, 아마존 등 여러 플랫폼에서 동시 판매하며, 각 플랫폼별로 광고를 집행합니다. 하지만:

1. **데이터 통합의 지옥**: 6개 이상의 플랫폼에 각각 로그인해서 데이터를 수집하고, 엑셀에 복사해서 수작업으로 통합 (하루 5.5시간 소요)
2. **고객여정 추적 불가**: "네이버에서 검색 → 인스타그램 광고 클릭 → 쿠팡에서 구매" 같은 멀티터치 여정을 99%의 셀러가 추적하지 못함
3. **인사이트 부재**: 데이터는 있지만 "다음에 무엇을 해야 하는가"에 대한 답이 없음
4. **전문성 장벽**: 비마케터는 ROAS, CTR, CVR 같은 용어조차 이해하기 어려움

### 시장 검증
설문조사 결과, "데이터 통합 기능"이 잠재 사용자들의 최우선 니즈로 확인됨.

## 3. 목표 (Goals)

### 노스스타 지표
**무료 → 유료 전환율 20%** - 사용자가 돈을 낼 만큼 명확한 가치 제공

### 사용자 목표
- **1차 목표**: 감이 아닌 팩트 기반 마케팅 의사결정 가능
- **2차 목표**: 데이터 정리 시간 90% 절감
- **3차 목표**: 전문가 없이도 고급 분석 수행

### 비즈니스 목표
- MVP 출시 3개월 내 50명 얼리어답터 확보
- 1년 내 1,000명 유료 고객 달성

## 4. 사용자 페르소나

### 주 페르소나: 멀티플랫폼 셀러 "김마켓"
- **배경**: 30대 중반, 네이버 스마트스토어 + 쿠팡 + 아마존에서 월 매출 1억원 규모 운영
- **일상**: 사무실 PC에서 업무, 이동 중 스마트폰으로 광고 성과 체크
- **고충**: 
  - 매일 아침 6개 플랫폼에 로그인해서 데이터 복사
  - "어디에 광고비를 더 쓸까?" 결정할 때마다 혼란
  - 전문 마케팅 대행사는 비용 부담
- **목표**: 혼자서도 데이터 기반으로 광고비 배분 결정하고 싶음
- **기술 수준**: 엑셀은 잘 다루지만, 복잡한 데이터 툴은 어려움

## 5. 사용자 스토리

### FEAT-1: 데이터 통합 레이어 (MVP 최우선)
- **AS-IS**: 매일 네이버, 쿠팡, 구글 애즈, 메타 등 6개 플랫폼에 각각 로그인해서 데이터를 엑셀에 복사 (2시간 소요)
- **TO-BE**: 마케트에 한 번 로그인하면 모든 플랫폼 데이터가 자동으로 통합되어 표시 (5분 소요)
- **가치**: 하루 1.5시간 × 월 20일 = 월 30시간 절약

**상세 요구사항**:
- 사용자가 각 플랫폼의 API 키를 한 번만 입력하면, 이후 자동으로 데이터 수집
- 지원 플랫폼:
  - 광고: 네이버 검색광고, GFA, 구글 애즈, 메타 광고, 카카오모먼트
  - 이커머스: 쿠팡 윙, 네이버 스마트스토어, 지마켓, 11번가
  - 애널리틱스: GA4, 네이버 애널리틱스
- 통합 대시보드에서 주요 지표 한눈에 확인:
  - 총 광고비, 총 매출, 전체 ROAS
  - 플랫폼별 비교 (막대 그래프)
  - 일자별 추이 (라인 차트)

### FEAT-2: 자연어 질의 엔진 (Phase 2)
- **AS-IS**: "왜 ROAS가 떨어졌지?" → 엑셀 피벗 테이블로 수작업 분석 (1시간)
- **TO-BE**: "왜 ROAS 떨어졌어?" 입력 → AI가 자동 분석 후 "인스타그램 30대 여성 타겟 광고의 클릭률은 높은데 구매 전환이 낮습니다. 랜딩페이지 로딩속도 확인 필요" 답변 (30초)
- **가치**: 진입장벽 90% 감소, 비전문가도 전문 분석 가능

**상세 요구사항**:
- ChatGPT 스타일 대화 인터페이스
- 자연어 입력 → OpenAI API → SQL 쿼리 생성 → 결과 해석 → 자연어 답변
- 추천 질문 템플릿 제공:
  - "이번 주 가장 잘 나간 상품은?"
  - "어제 전환율이 떨어진 이유는?"
  - "30대 여성 타겟팅 효율 분석해줘"

### FEAT-3: 자동 리포트 생성 (Phase 2)
- **AS-IS**: 월말마다 PPT 리포트 작성 (3시간)
- **TO-BE**: "이번 달 리포트 생성" 버튼 클릭 → 30초 만에 완성
- **가치**: 월 3시간 절약, 일관된 품질

**상세 요구사항**:
- 주간/월간 자동 리포트
- 구성:
  - Executive Summary (핵심 지표 3개)
  - 플랫폼별 성과 비교
  - 전월 대비 증감 분석
  - 주요 이슈 및 추천 액션
- PDF 다운로드 또는 이메일 발송

## 9. 해결 가설

### 핵심 가설
"이커머스 셀러는 데이터 통합만 해결되어도 월 $99를 기꺼이 지불할 것이다"

### 검증 방법
1. **얼리어답터 50명 무료 제공** (3개월)
   - 관찰: 주간 활성률 60% 이상 유지?
   - 학습: 어떤 기능을 가장 많이 사용?
2. **유료 전환 제안** (3개월 후)
   - 관찰: 전환율 20% 달성?
   - 학습: 거부 이유는? 가격? 기능?
3. **다음 가설**
   - 전환율 <10%: 가치 부족 → 기능 보강 또는 피벗
   - 전환율 10~20%: 가격 조정 필요
   - 전환율 >20%: 확장 단계 진입

## 10. 실험-학습 루프

### Phase 1 (MVP, 3개월)
- **실험**: 데이터 통합 레이어만 제공
- **관측**: 사용 빈도, 연동 플랫폼 수, 세션 시간
- **학습**: 어떤 플랫폼 데이터를 가장 자주 확인하는가?
- **다음**: 자주 보는 지표 중심으로 자연어 질의 기능 설계

### Phase 2 (6개월)
- **실험**: 자연어 질의 + 자동 리포트 추가
- **관측**: 질의 유형 분석, 리포트 다운로드율
- **학습**: 어떤 질문을 가장 많이 하는가?
- **다음**: 자주 묻는 질문을 자동 인사이트로 전환

## 11. Sticky Loop (리텐션 메커니즘)

### 온보딩 → 핵심작업 → 리텐션 루프

```
1. 온보딩 (첫 방문)
   ↓
2. API 연동 (3개 플랫폼, 5분)
   ↓
3. 첫 대시보드 확인 (Aha Moment!)
   ↓
4. 일일 루틴 형성
   - 매일 아침 9시 이메일 알림: "어제 광고비 20% 증가"
   - 클릭 → 대시보드 확인
   ↓
5. 주간 루틴
   - 매주 월요일 주간 리포트 자동 생성
   ↓
6. 의사결정 의존
   - "광고비 어디에 더 쓸까?" → 마케트 데이터 확인
   ↓
7. 이탈 방지
   - 3일 미접속 시: "주요 지표 변화 알림"
   - 무료 기간 종료 전: "지난 3개월간 30시간 절약했습니다"
```
