## 핵심 사용자 여정

### FEAT-1: 데이터 통합 레이어 - 첫 온보딩 흐름

```mermaid
graph TD
    A[랜딩페이지 방문] --> B{회원가입/로그인}
    B -->|신규| C[이메일 회원가입]
    B -->|기존| D[로그인]
    
    C --> E[온보딩 시작]
    D --> E
    
    E --> F[플랫폼 선택 화면]
    F --> G{연동할 플랫폼 선택}
    
    G -->|네이버| H1[네이버 API 키 입력]
    G -->|쿠팡| H2[쿠팡 API 키 입력]
    G -->|구글| H3[구글 OAuth 인증]
    G -->|메타| H4[메타 Access Token 입력]
    
    H1 --> I[API 연결 테스트]
    H2 --> I
    H3 --> I
    H4 --> I
    
    I --> J{연결 성공?}
    J -->|성공| K[데이터 수집 시작]
    J -->|실패| L[에러 메시지 표시]
    L --> F
    
    K --> M[최초 데이터 로딩 중... 약 30초]
    M --> N[대시보드 첫 화면 표시]
    
    N --> O[Aha Moment: 통합된 데이터 확인!]
    O --> P[가이드 툴팁: 주요 기능 소개]
    P --> Q[온보딩 완료]
```

### 일일 루틴 흐름 (Sticky Loop)

```mermaid
graph TD
    A[이메일 알림 수신: 어제 성과 요약] --> B[이메일 클릭]
    B --> C[대시보드 자동 로그인]
    
    C --> D[오늘의 주요 지표 확인]
    D --> E{이상 징후 발견?}
    
    E -->|정상| F[간단히 확인 후 종료]
    E -->|이상| G[상세 분석 필요]
    
    G --> H[특정 플랫폼 클릭]
    H --> I[세부 데이터 드릴다운]
    I --> J[문제 원인 파악]
    
    J --> K{액션 필요?}
    K -->|필요| L[외부 플랫폼에서 조치]
    K -->|불필요| F
    
    L --> M[다음날 성과 확인 대기]
    M --> A
```

### FEAT-2: 자연어 질의 흐름 (Phase 2)

```mermaid
graph TD
    A[대시보드에서 챗 아이콘 클릭] --> B[질문 입력창 표시]
    
    B --> C{질문 방식 선택}
    C -->|직접 입력| D[자연어 질문 타이핑]
    C -->|템플릿 선택| E[추천 질문 클릭]
    
    D --> F[질문 전송]
    E --> F
    
    F --> G[AI 분석 중... 로딩 표시]
    G --> H[데이터베이스 쿼리 실행]
    H --> I[결과 해석]
    
    I --> J[답변 생성 및 표시]
    J --> K[관련 차트 자동 생성]
    
    K --> L{추가 질문?}
    L -->|있음| D
    L -->|없음| M[대시보드 복귀]
    
    J --> N[답변 저장 옵션]
    N -->|저장| O[리포트에 추가]
    N -->|스킵| M
```

### FEAT-3: 자동 리포트 생성 흐름 (Phase 2)

```mermaid
graph TD
    A[리포트 메뉴 클릭] --> B[리포트 목록 표시]
    
    B --> C{액션 선택}
    C -->|새 리포트| D[리포트 설정 화면]
    C -->|기존 조회| E[리포트 상세 보기]
    
    D --> F[기간 선택: 주간/월간/커스텀]
    F --> G[포함할 플랫폼 선택]
    G --> H[리포트 생성 버튼 클릭]
    
    H --> I[데이터 집계 중... 약 10초]
    I --> J[리포트 미리보기 표시]
    
    J --> K{만족?}
    K -->|아니오| L[설정 수정]
    L --> F
    K -->|예| M[리포트 저장]
    
    M --> N{다음 액션}
    N -->|다운로드| O[PDF 생성 및 다운로드]
    N -->|공유| P[이메일 발송 or 링크 생성]
    N -->|완료| Q[리포트 목록으로]
    
    E --> R[PDF 뷰어로 보기]
    R --> S[다운로드 or 공유]
```

### 에러 처리 흐름

```mermaid
graph TD
    A[사용자 액션] --> B{에러 발생?}
    
    B -->|API 키 만료| C[알림: API 키 갱신 필요]
    C --> D[설정 페이지로 이동]
    D --> E[API 키 재입력]
    E --> F[연결 재시도]
    
    B -->|네트워크 에러| G[알림: 일시적 오류]
    G --> H[자동 재시도 3회]
    H --> I{성공?}
    I -->|실패| J[고객센터 문의 안내]
    I -->|성공| K[정상 진행]
    
    B -->|데이터 없음| L[안내: 데이터 수집 대기 중]
    L --> M[예상 시간 표시]
    M --> N[새로고침 버튼 제공]
    
    B -->|권한 부족| O[알림: 플랜 업그레이드 필요]
    O --> P[가격 페이지로 안내]
```

## 주요 화면별 상세 흐름

### 1. 온보딩 - 플랫폼 연동

**화면 구성:**
```
┌─────────────────────────────────────┐
│  마케트에 오신 것을 환영합니다!      │
│  광고 플랫폼을 연동해주세요          │
├─────────────────────────────────────┤
│                                      │
│  [네이버 검색광고]  [쿠팡 윙]       │
│  [구글 애즈]        [메타 광고]     │
│  [카카오모먼트]     [11번가]        │
│                                      │
│  최소 1개 이상 연동이 필요합니다     │
│                                      │
│  [나중에 하기]      [다음 →]        │
└─────────────────────────────────────┘
```

**사용자 액션:**
1. 플랫폼 카드 클릭
2. 모달 팝업: API 키 입력 폼
3. "연동하기" 버튼 클릭
4. 로딩 → 성공/실패 메시지
5. 다른 플랫폼 계속 연동 or "다음" 클릭

---

### 2. 대시보드 메인

**화면 구성:**
```
┌──────────────────────────────────────────────┐
│  마케트                         [알림] [설정] │
├──────────────────────────────────────────────┤
│  최근 7일 성과                                │
│  ┌──────┐  ┌──────┐  ┌──────┐              │
│  │ 총 광고비 │ 총 매출 │ ROAS  │              │
│  │ 1.2M    │ 3.8M   │ 3.2   │              │
│  └──────┘  └──────┘  └──────┘              │
│                                              │
│  플랫폼별 성과                                │
│  [막대 그래프]                               │
│                                              │
│  일자별 추이                                  │
│  [라인 차트]                                 │
│                                              │
│  [💬 AI에게 질문하기]                        │
└──────────────────────────────────────────────┘
```

**사용자 액션:**
1. 지표 카드 클릭 → 세부 화면
2. 그래프 호버 → 툴팁 표시
3. "AI에게 질문하기" 클릭 → 챗봇 열림

---

### 3. 설정 - API 키 관리

**화면 구성:**
```
┌──────────────────────────────────────┐
│  설정                                 │
├──────────────────────────────────────┤
│  연동된 플랫폼                         │
│                                       │
│  ✅ 네이버 검색광고                   │
│     마지막 동기화: 2시간 전            │
│     [재연동] [삭제]                   │
│                                       │
│  ✅ 쿠팡 윙                           │
│     마지막 동기화: 1시간 전            │
│     [재연동] [삭제]                   │
│                                       │
│  ❌ 구글 애즈                         │
│     API 키 만료됨                     │
│     [갱신하기]                        │
│                                       │
│  [+ 새 플랫폼 추가]                   │
└──────────────────────────────────────┘
```

**사용자 액션:**
1. "재연동" → API 키 재입력 모달
2. "삭제" → 확인 다이얼로그 → 연동 해제
3. "갱신하기" → 새 API 키 입력

## 상태 관리 흐름

### 인증 상태

```
미인증 → 로그인/회원가입 → 인증됨
                              ↓
                        온보딩 필요?
                        /           \
                       예            아니오
                       ↓              ↓
                    온보딩 화면     대시보드
```

### 데이터 로딩 상태

```
초기 상태
  ↓
API 호출
  ↓
로딩 중 (스켈레톤 UI)
  ↓
성공 → 데이터 표시
실패 → 에러 메시지 + 재시도 버튼
```

## 반응형 UI 흐름

### 모바일 (< 640px)

- 햄버거 메뉴
- 카드 1열 레이아웃
- 간소화된 차트 (작은 화면)
- 하단 네비게이션 바

### 태블릿 (640px ~ 1024px)

- 접을 수 있는 사이드바
- 카드 2열 레이아웃
- 전체 차트 표시

### 데스크톱 (> 1024px)

- 고정 사이드바
- 카드 3열 레이아웃
- 큰 차트 + 상세 정보
